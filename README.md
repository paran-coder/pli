# Pli · 플리

참고 채널 분석부터 곡 기획, 음악·이미지 생성, CapCut 전달까지 이어지는 플레이리스트 제작 도구입니다.

이 ZIP의 내용물을 GitHub 저장소 최상위에 올립니다. Vercel에서는 저장소 최상위를 루트로 사용하며 출력 디렉터리는 public입니다.

방문 수는 Vercel 대시보드에서 Web Analytics를 활성화하고 배포한 뒤 확인합니다. 공유 이미지의 절대 HTTPS 주소는 실제 배포 주소를 확정한 뒤 설정합니다.

Windows에서 로컬 실행은 Node.js 22 이상을 설치하고 2026-11-05-PlayL-start-v0.8.2.cmd를 실행합니다. 웹앱의 브릿지 다운로드는 public 아래의 현재 배포용 ZIP을 제공합니다.
