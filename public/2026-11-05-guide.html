PlayL · 플리 사용방법

참고 채널에서 제작 방향을 찾고, 원곡과 이미지를 준비해 CapCut에서 편집합니다.

이 안내는 별도 탭에서 열립니다. 원래 작업 탭으로 돌아가 계속 진행하세요.

처음 시작하기 · 사이트에서 준비

  1. 작업 화면 왼쪽 시작·설치 확인을 엽니다.
  2. 로컬 브릿지가 없으면 화면의 PlayL · 플리 브릿지 다운로드를 누릅니다. Node.js가 없으면 공식 다운로드로 설치합니다.
  3. ZIP 전체를 풀고 포함된 2026-11-05-PlayL-start-v0.6.1.cmd를 실행합니다. 현재는 사이트에서 설치를 안내하는 실행 묶음이며 별도 자동 설치 마법사는 아닙니다.
  4. 사이트에서 브릿지 연결을 다시 확인합니다. 배포 사이트를 쓸 때는 로컬 연결과 설정에서 해당 HTTPS origin을 등록하고 연결 코드를 입력합니다.
  5. 확인된 설치 상태에서 없는 도구만 공식 다운로드 안내로 준비하고 설치 상태 다시 확인을 누릅니다. 설치 확인과 실행·로그인·모델 준비 완료는 별개입니다.

로컬 브릿지가 GPU·VRAM·RAM과 알려진 설치 위치/PATH를 확인합니다. 임의 위치의 설치는 찾지 못할 수 있습니다. YuE2는 앱 버전과 모델 구성(BF16/Q8 등)을 구분해 PC 사양에 맞는 후보를 안내하며, Studio에서 모델·드라이버 준비 상태를 최종 확인합니다.

YuE2 개발자 요구 사양·모델 안내 ↗를 참고한 후보 안내이며 실행 보증은 아닙니다. 사양 확인을 못 하면 추천을 보류합니다.

이미지 AI 생성과 새 CapCut 초안의 자동 등록은 아직 제공하지 않습니다. 현재 지원 범위를 확인하세요.

YouTube API 키 준비·저장

1. Google Cloud에서 준비

  1. Google Cloud Console ↗에서 프로젝트를 만들거나 선택합니다. 이 프로젝트는 Google API 관리용이며 PlayL 작업과는 별개입니다.
  2. ‘API 및 서비스 → 라이브러리’에서 YouTube Data API v3를 찾아 사용 설정합니다.
  3. ‘API 및 서비스 → 사용자 인증 정보’에서 사용자 인증 정보 만들기 → API 키로 일반 API 키를 만듭니다. 공개 채널 수집에는 서비스 계정 JSON이나 OAuth 클라이언트 파일을 넣지 않습니다.
  4. 키의 API 제한 대상을 YouTube Data API v3로 지정합니다. API를 활성화한 프로젝트와 키를 만든 프로젝트가 같은지 확인하세요.

2. PlayL에서 저장

  1. 작업 화면 왼쪽의 연결과 설정을 엽니다.
  2. ‘YouTube 데이터 연결 → YouTube API 키’에 키 문자열을 붙여 넣고 키 저장을 누릅니다.
  3. 저장 후 입력창이 접히고 키 등록됨 · 연결 확인 전으로 바뀝니다. 실제 연결 확인을 누르거나 채널 수집에 성공하면 연결 확인됨이 표시됩니다. 키를 바꿀 때만 ‘키 변경’을 사용합니다.

API 키는 채팅·공유 화면·GitHub에 올리지 말고 앱의 키 입력란에 직접 저장하세요. PC의 비공개 연결 설정에 저장되며 저장 후 화면에 키를 다시 표시하지 않습니다.

키에 웹사이트/IP 제한을 설정할 때

현재 YouTube 요청은 PC의 로컬 브릿지가 Google로 보냅니다. 브라우저용 HTTP 리퍼러 제한은 이 방식과 맞지 않아 요청이 거절될 수 있습니다. IP 제한은 Google로 요청하는 PC의 공인 출구 IP에 맞춰야 하며, 인터넷 환경이 바뀌면 다시 확인해야 합니다. 127.0.0.1은 Google에서 보는 공인 IP가 아닙니다.

Google 공식 키 제한 안내 ↗

Google 콘솔의 메뉴 이름은 언어·화면 개편에 따라 달라질 수 있습니다. YouTube 시작 안내 ↗ · API 키 만들기 안내 ↗

01 참고 채널 분석

  1. 채널 URL 또는 @핸들을 입력합니다. 예: https://www.youtube.com/@채널핸들. 개별 영상·플레이리스트 주소 대신 채널 주소를 사용하세요.
  2. 최근 10·20·50개 중 수집 범위를 선택하고 입력란 옆 데이터 수집을 누릅니다. 채널을 모르면 키워드 검색 후 ‘이 채널 수집’을 선택합니다.
  3. 표본 수·게시 기간·길이별 비교·긴 영상 조회수 상위·제목 키워드를 확인합니다. 조회수 상위는 최근 수집 표본 안의 순위입니다.
  4. AI로 제작 방향 분석을 실행합니다. 로그인된 GPT/Codex 또는 Claude CLI가 필요합니다. 같은 채널 화면에서 진행 상태·오류·분석 결과를 확인합니다. 작업 기록으로 자동 이동하지 않습니다.
  5. 근거 영상과 제작 방향을 검토한 뒤 이 분석을 곡 기획에 반영을 눌러 다음 단계로 연결합니다.

AI 해석은 제목·설명 등 메타데이터 기반 추정입니다. 실제 음악을 듣거나 썸네일 픽셀을 분석한 결과가 아닙니다. BPM·최적 업로드 시간·시청 지속률·수익을 확인했다고 해석하지 마세요. 길이 3분 이하가 곧 Shorts라는 뜻도 아닙니다.

참고 채널 없이 직접 기획할 수도 있습니다. 실제 채널 재수집·Codex 해석을 확인했습니다. 예전 자료는 다시 분석할 때 설명과 트랙 목록을 갱신합니다. 제작 제안의 곡 수·길이·반복·총길이는 계산 검사하며, 반복은 설명의 단서와 실제 오디오 확인을 구분합니다. 모순된 이전 제안은 재분석 전 반영할 수 없습니다.

02 곡 기획·가사

  1. 곡 기획 설정을 펼쳐 이름·장르·분위기·가사 언어·곡 수·직접 제작 방향을 입력합니다.
  2. GPT/Codex와 Claude의 사용 순서를 정합니다. ‘순서 바꾸기’로 변경할 수 있습니다. 연결과 설정에서 모델명을 지정하며, 비우면 CLI 기본값을 사용합니다.
  3. 기획·가사 생성을 누르고 같은 화면에서 생성된 초안의 제목·스타일·가사를 검토해 현재 작업에 추가합니다. 기존 곡은 유지됩니다. 직접 곡 추가로 작성할 수도 있습니다.
  4. 곡별 제목·가사·스타일을 수정합니다. 기존 곡은 자동 교체되지 않으므로 중복 곡이 생기지 않았는지 확인하세요.

사용량 한도 오류가 확인될 때만 다음 제공자로 전환합니다. 로그인·네트워크 오류는 한도 소진으로 간주하지 않으며 잔여 크레딧을 추정하지 않습니다.

03 음악 생성·선택

  1. 곡 기획 설정에서 YuE2 Studio 또는 Suno를 선택합니다.
  2. 연결과 설정에서 엔진 연결을 확인합니다. YuE2는 프로젝트용 실행 스크립트 2026-11-04-YuE2-workspace-start-v0.1.0.ps1로 시작하고 프로젝트 내부 저장 경로·모델 준비 상태를 확인합니다.
  3. 곡별 생성 버튼으로 요청하거나, 기존 음원 파일을 가져옵니다. 생성 결과는 작업 기록에서 검토한 뒤 이 음원 선택으로 연결합니다.
  4. 후보를 미리 듣고 사용할 음원을 확정합니다. Suno 실제 계정 연결·생성·다운로드는 아직 검증하지 않았습니다.
YuE2 연결이 끊기거나 생성 추적을 중단했다면

‘기존 생성 결과 확인·복구’로 같은 작업 ID를 조회하세요. 새 생성 요청을 다시 보내는 기능이 아닙니다. ‘생성 추적 중단’은 YuE2의 실제 GPU 생성을 취소하지 않으므로 Studio에서 상태를 확인한 뒤 판단하세요.

04 무음·음량 조정

  1. 곡별 무음 구간 분석을 실행하고 작업 기록에서 추천 트림을 검토·적용합니다.
  2. 시작·끝 시간을 조정하고 전주·잔향이 잘리지 않는지 직접 듣습니다.
  3. 출력 시 음량 통일 여부를 정하고 상단 조정 확인 완료로 확인 상태를 기록합니다.

CapCut 전달용 WAV에는 트림·음량 통일(선택)·시작과 끝 페이드가 반영됩니다. 원본 음원은 보존합니다. 자동 처리가 청취 검수를 대신하지 않습니다.

05 이미지 준비

  1. 외부에서 만든 이미지를 곡별로 이미지 가져오기로 첨부하거나 YuE2가 제공한 커버를 선택합니다.
  2. 같은 배경을 쓰려면 ‘이 이미지를 모든 곡에 적용’을 선택합니다.
  3. 모든 곡에 사용할 이미지가 지정되었는지 확인합니다.

앱 안의 AI 이미지 생성은 아직 미구현입니다. 현재는 준비한 이미지 파일을 첨부하는 단계입니다.

06 CapCut 전달

  1. 곡 순서를 확인하고 모든 곡에 음원·이미지가 연결됐는지 확인합니다.
  2. CapCut 프로젝트 만들기를 누르고 작업 완료를 기다립니다.
  3. 결과에 표시된 PC 초안 폴더와 ZIP을 보관합니다. 이미지와 음악이 분리된 타임라인이며 최종 편집·영상 내보내기는 CapCut에서 진행합니다.
자동 등록은 아직 없습니다. ZIP 저장만으로 CapCut 프로젝트 목록에 자동으로 나타나지 않습니다. 현재 확인된 것은 승인된 테스트 초안 1개를 등록해 CapCut 9.6에서 열기·30초 재생·저장·재열기한 결과입니다. 새 작업의 등록 절차는 별도 보완이 필요합니다.

초안은 현재 PC의 Resources 미디어 경로를 참조합니다. 폴더를 삭제하지 마세요. 다른 PC로 옮기면 미디어 경로를 다시 연결해야 할 수 있습니다. 현재 ZIP은 4GB 미만을 지원합니다.

CapCut 편집이 필요 없을 때는 접힌 ‘보조 기능 · MP4 직접 만들기’를 사용할 수 있습니다. 긴 영상·여러 곡·다른 CapCut 버전은 별도 검증 대상입니다.

작업 저장·불러오기

상단 저장을 눌러 작업을 남깁니다. ‘저장하지 않은 변경 사항’이 표시되면 현재 편집 내용을 다시 저장하세요. 다음에 왼쪽 ‘저장·불러오기’ 목록에서 불러올 수 있습니다.

‘새 작업’은 새로운 임시 작업을 시작합니다. 저장하지 않은 변경이 있다면 이동 전 확인합니다. 작업 화면 새로고침과 브릿지 종료 전 저장 상태를 확인하세요.

문제 해결

키를 등록했는데 수집에 실패해요

키를 만든 Google 프로젝트에서 YouTube Data API v3가 활성화됐는지, API·클라이언트 제한이 맞는지 확인하세요. 저장 성공은 API 호출 성공이 아닙니다. 할당량 오류는 Google 콘솔에서 사용량을 확인하고, 오류 메시지는 키 문자열을 제외해 공유하세요.

로컬 브릿지 연결이 안 돼요

PC 실행 스크립트를 켜고 터미널이 열려 있는지 확인하세요. 로컬 주소는 http://127.0.0.1:43119 입니다. 배포된 웹앱과 로컬 브릿지 연결은 아직 실제 배포 환경에서 검증하지 않았습니다.

채널 주소 형식 오류가 나요

/@핸들, /channel/채널ID, /user/사용자명 형식을 사용하세요. /c/별칭, 개별 영상, 플레이리스트 URL 대신 실제 채널의 @핸들을 복사하세요.

AI나 음악 생성이 실패했어요

작업 기록의 오류와 제공자 로그인·엔진 연결 상태를 확인하세요. 실제 생성 여부가 불명확하면 같은 요청을 즉시 반복하지 말고 기존 작업 ID를 먼저 조회하세요.

CapCut에서 파일을 찾을 수 없다고 해요

원래 초안 결과의 Resources 폴더가 남아 있는지 확인하세요. ZIP을 다른 위치에 풀어도 내부의 절대 미디어 경로가 자동으로 바뀌지는 않습니다. 원본 결과 폴더를 보존하고 CapCut의 미디어 재연결을 확인하세요.

곡 만들기부터 CapCut까지

  1. 음악 생성·선택에서 YuE2 Studio를 선택하고 실행 및 연결을 누릅니다.
  2. 곡 카드에서 생성하거나 음원 없는 곡을 일괄 생성합니다. 단일 후보는 원래 곡에 연결됩니다.
  3. 포함할 곡으로 계속을 누른 뒤 무음 분석과 조정을 확인합니다.
  4. 이미지 단계에서 커버를 변경하거나 가사로 새 후보를 만듭니다. 새 이미지는 로그인된 Codex CLI로 생성합니다.
  5. CapCut 초안이 완료되면 CapCut에서 열기를 누릅니다. 앱의 프로젝트 목록에서 새 초안을 선택합니다.

배포된 웹앱에서 PC 브릿지 연결

브릿지 ZIP을 작업 폴더에 풀고 Windows PowerShell 7에서 PlayL 설치 스크립트를 실행합니다. 배포 담당자는 공식 HTTPS 주소를 설치 설정에 지정합니다. 웹앱에서 브릿지 연결을 눌러 Windows의 앱 실행 안내와 PlayL 승인 창을 확인하세요. 음원과 이미지는 브라우저에서 같은 PC의 브릿지로 전달합니다.

YuE2 처음 사용하기

시작·설치 확인에서 GPU 메모리와 RAM, YuE2 설치 상태를 확인합니다. 이미 설치돼 있으면 프로젝트용 복사본을 준비하고, 설치가 필요하면 공식 다운로드로 이동합니다. 모델이 준비되지 않았다면 Studio 모델 설정에서 권장 구성을 다운로드한 뒤 PlayL에서 다시 연결하세요.
